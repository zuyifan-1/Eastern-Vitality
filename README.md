# Eastern Vitality

Eastern Vitality is a real-time pose training web application that combines reference video guidance with live webcam tracking. Users can compare their movements against a reference and receive visual feedback through skeleton overlay.

## Live Demo

https://eastern-vitality-1.onrender.com

## Features

- Real-time pose tracking using webcam
- Reference video and live skeleton comparison
- Skeleton overlay visualization
- Pose detection with MediaPipe
- Basic scoring feedback

## Tech Stack

Frontend: HTML, JavaScript  
Backend: Flask (Python)  
Pose Detection: MediaPipe  
Deployment: Docker + Render

## Notes

- Webcam access is required.
- The Render free tier may take a short time to wake up after inactivity.
